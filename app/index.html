        About this guide

        Names, descriptions and grades are the official PlayStation 5 list as published by Exophase and PSNProfiles on 18 November 2026 (55 trophies: 1 platinum, 2 gold, 6 silver, 46 bronze; about 28 hidden on PlayStation until earned; no online trophies). Every guide is written in our own words for this page, and each one names its sources — a guide that cites no source earns no trust, so where a location or step could not be verified before the game's 19 November 2026 launch, the guide says so honestly instead of inventing one.

        Progress is saved only in this browser (localStorage) and can be exported to a JSON file and imported back. The guide is a set of static files: it loads nothing from the network and works with the network off.
